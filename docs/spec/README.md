# Specification (extracted from AGENTS.md)

Read one file when the task points to it. Never load the whole folder.

Section numbers are the original ones (`§2.6` is "Official hyperparameters" in
`10-official-conventions.md`); headings were kept unchanged when the file was split, so a
reference from code comments still resolves. The *rules* are not here: they are the `R1..R15`
contract in [`AGENTS.md`](https://github.com/nbadino/tabularium/blob/main/AGENTS.md).

|---|---|---|
| [`00-mission.md`](00-mission.md) | Product mission and the one-sentence promise | you need to know what the product is |
| [`10-official-conventions.md`](10-official-conventions.md) | Upstream facts: prompts, coordinates, OTSL, JSONL, pixels, hyperparameters, VRAM | you touch parsing, datasets or training data |

| [`50-datasets.md`](50-datasets.md) | JSONL families and the official Paddle views | you touch the dataset builder |
| [`60-taxonomy.md`](60-taxonomy.md) | Labels, page genres, native vocabularies and aliases | you touch labels or prefill mapping |
| [`61-transcription-conventions.md`](61-transcription-conventions.md) | Per-project transcription rules | you touch annotation or export warnings |
